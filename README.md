# مواقيت | Mawaqeet

تطبيق تقويم إسلامي عربي يعمل دون اتصال بالإنترنت، مبني بـ Kotlin وJetpack Compose.

## الإصدار التأسيسي 0.2.0
- واجهة عربية RTL بطابع إسلامي وفلكي مع بطاقات شفافة مستوحاة من Liquid Glass.
- تحديد الإحداثيات عبر GPS مباشرة، دون صلاحية إنترنت.
- تحويل التاريخ الميلادي إلى هجري محلياً باستخدام تقويم Android/Java الهجري.
- مؤشر تقريبي لعمر القمر وطورِه ونسبة إضاءته، مع تقدير وقت المحاق التالي.
- مواقيت الصلاة والشروق والغروب وطول النهار بحسابات محلية أولية.
- مساحة تمهيدية لتوسعة رصد النجوم والكواكب.

## تنبيه مهم بشأن الهلال
التاريخ الهجري المعروض حسابي وقد يختلف عن التاريخ المعتمد في بلدك بسبب اختلاف ثبوت الهلال. طور القمر وعمره مؤشرات فلكية تقريبية فقط، ولا تمثل تنبؤاً موثوقاً بإمكانية رؤية الهلال. قرار دخول رمضان والأشهر الهجرية يُرجع فيه إلى الجهة الشرعية المختصة والرؤية المعتمدة محلياً.

## حدود النسخة الحالية
- مواقيت الصلاة تستخدم زوايا افتراضية (الفجر 18° والعشاء 17°) وطريقة العصر القياسية؛ ستضاف طرق الحساب وإعدادات البلدان والتعديلات المحلية.
- مؤشر القمر يستخدم دورة اقترانية متوسطة، وليس نموذجاً فلكياً دقيقاً لرصد الهلال.
- لا توجد بعد حسابات مواقع النجوم والكواكب أو نمذجة الأفق والطقس.

## البناء
يتطلب JDK 17 وGradle 8.9:
`gradle assembleDebug`

ينشأ APK في `app/build/outputs/apk/debug/app-debug.apk`.
يبني GitHub Actions نسخة Debug تلقائياً عند كل تحديث إلى الفرع main.
